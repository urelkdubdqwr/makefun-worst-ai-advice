One line, at most 140 characters: the worst possible advice an AI could give, funny and specific enough to follow. main.py writes it to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
